# End Zone Defense

An NFL tower defense game you play in your browser. Place Josh Allen, Amon-Ra St. Brown, Derrick Henry, Brock Bowers, Myles Garrett, Maxx Crosby, Patrick Surtain II and Brandon Aubrey to stop waves of Vicks before they reach your end zone.

**Play it:** https://antabb60-tech.github.io/nfl-tower-defense/

The whole game is the single file `index.html`. No install or build step.
